# 管理器视觉验收记录

- 设计方向：白色主体、低饱和暖色强调、单页紧凑布局。
- 应用图标源文件：`design/vision-mcp-icon-source.png`。
- 发布图标：`design/vision-mcp-icon.png` 与 `packaging/vision-mcp.ico`。

## 验收重点

- 窗口启动时在主屏幕居中，默认尺寸可展示服务商、Agent 列表、测试状态和底部操作区。
- 同一服务商用一个紧凑选择器配置多个能力模型；智谱默认显示“视觉 2 · 生图 1 · 视频 1”，展开后支持勾选预设和填写多个自定义模型 ID。
- 至少保留一个服务商和一个视觉理解模型；重复的服务商/API 地址/协议组合被拒绝。
- API Key 输入框长于服务商和模型字段，显隐按钮及“获取 API Key”链接对齐。
- Agent 同时展示安装状态和配置状态；标准 MCP 配置可以复制给其他 Agent。
- 操作顺序为“一键配置并测试、仅保存、关闭、更多操作”；菜单始终向窗口内展开。
- 结果区域支持展开详细日志，错误信息不显示 API Key、Authorization 或媒体内容。
- WebView2 页面由程序内嵌加载，不启动 HTTP 服务。

## 本轮验证

- 参考：已确认的白底、低饱和暖色管理器页面。
- 实现：单服务商行保持原有字段比例，模型选择器替代重复的多行智谱配置。
- 交互：实际展开选择器，确认四个默认模型均被勾选；取消视频模型并填写两个自定义图片模型后，摘要正确更新为“视觉 2 · 生图 3”。
- 布局：默认折叠状态仍在一屏内展示主要功能，固定底部操作区未遮挡模型与 Agent 内容。
- 浏览器控制台：未发现脚本错误。

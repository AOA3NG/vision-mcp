使用说明

快速开始

  1. 选择服务商和模型，填写至少一个 API Key。
  2. 勾选已安装的 Agent。
  3. 点击“一键配置并测试”，依次检查 Agent、MCP 协议和模型连接。

模型与备用顺序

视觉理解、图片生成和视频生成可以分别选择多个模型。列表中的顺序就是调用顺序；自定义模型请点击“添加其他模型”，每个输入框只填写一个模型 ID。

智谱图片与视频生成模型默认不勾选，可按需启用。百炼 Coding Plan 的 Qwen3.7 Plus 用于图片和视频理解，不提供图片或视频生成输出。

多个 API Key

每组服务商配置对应一个 Key。如需备用 Key，请点击“添加服务商”新增一组；可以选择相同服务商和模型，程序会按配置顺序尝试。所有 Key 只保存在 Windows Credential Manager。

Agent 调用方式

Vision MCP 使用 stdio。Agent 调用时按需启动服务，不需要开机自启，不会弹出管理器窗口，也不会运行 HTTP 服务。

Claude Code 等非多模态 Agent：复制图片后不要粘贴进对话，输入“请调用 Vision MCP 的 analyze_clipboard_image 分析剪贴板图片”。直接粘贴可能在调用 MCP 前被基础模型拒绝。

隐私提醒

图片、视频和文档会发送到你配置的模型服务商。自定义 API 地址必须是可信 HTTPS 地址，请勿在日志或 Issue 中粘贴 API Key 和私人媒体内容。
